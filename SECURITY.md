# Güvenlik

Client Secret, uygulama tokenı, çerez ve özel bağlantılarınızı issue veya pull
request içine koymayın. Yerel ayar, indirme ve hata dosyaları Git dışında tutulur.
Örnek ayarlar yalnız `YOUR_...` yer tutucuları içermelidir.

Bir secret yanlışlıkla herkese açık paylaşılırsa Kick geliştirici ayarlarından
yenileyin; dosyayı silmek Git geçmişindeki değeri kaldırmaz. Yeni değeri yalnız
kendi `kick-config.js` dosyanıza veya ortam değişkenlerinize yazın.

Bir güvenlik sorunu bulduysanız GitHub deposunun Security bölümündeki özel
bildirim seçeneğini kullanın. Bu seçenek görünmüyorsa açık issue'da yalnızca
özel bir bildirim kanalı isteyin; açığın ayrıntılarını veya gerçek anahtarları
paylaşmayın.
