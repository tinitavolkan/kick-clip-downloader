# Güvenlik

Özel bağlantılarınızı, kişisel dosyalarınızı ve tarayıcı çerezlerinizi issue veya
pull request içine koymayın. İndirme listeleri, videolar, yerel kayıtlar ve hata
raporları Git dışında tutulur. Sorun bildirirken kişisel verileri temizleyin.

Bir güvenlik sorunu bulduysanız deponun Security bölümündeki özel bildirim
seçeneğini kullanın. Bu seçenek görünmüyorsa açık issue'da yalnızca özel bir
bildirim kanalı isteyin; açığın ayrıntılarını paylaşmayın.
